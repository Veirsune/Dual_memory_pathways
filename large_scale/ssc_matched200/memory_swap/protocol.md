# SSC midpoint stable-memory exchange

Use the fixed 128-wide GDSM checkpoint, verified prepared test inputs and frame boundary from the published midpoint reset. Use only clean speech. No training, parameter selection or selection on model predictions.

For each official test utterance find two donors from the same speaker whose true word classes differ from the recipient and from one another. Rank other-class utterances by similarity of their last 125 sensor frames. Sum events into 5 contiguous time bins by 14 contiguous frequency bins, apply log(1 + count) elementwise and take cosine similarity. Choose the nearest eligible donor, then the nearest eligible donor from a third class. Break ties by original test index. Donors may be reused. Exclude speakers with fewer than three distinct word classes. Similarity is in cochlear event counts, not a verified phonetic transcription. Only the offline pairing uses the donor suffix.

Stop after frame 125. Save both layers' stable states, candidates, membrane voltages, layer statistics and global gate history. Apply three conditions to the same recipient: carry its own state, replace only its two stable states with donor A's, or replace only those states with donor B's. All other recipient states and all 125 suffix frames are identical; subsequent writes run normally. Predict the original word by the largest mean suffix logit.

Primary outcome: frequency of predicting the actual donor class minus frequency of predicting the alternate eligible donor class, averaged equally across the two swap conditions (percentage points). A generic loss of recipient accuracy alone need not favor the actual donor. Secondary outcomes: actual donor prediction against the own-state baseline, recipient recognition, and change in the A-minus-B mean-logit contrast when using A's state versus B's (half the difference). Report paired 95% percentile intervals from 10,000 speaker-cluster resamples (seed 413), conditional on checkpoint and deterministic pairing. Check the unchanged predictions against the archived clean-midpoint study and check a swap against an independent batched forward computation.
