# 板块4：参数、缓存、有效操作与闭门读取复用

仅对板块3固定第20轮DMP/Commit进行推理分析，无新训练。全部264段官方TEST，干净及中途/尾部静音、1x/3x泊松噪声，L20/40/80。轨迹分析batch=16（分类主评估仍为batch=4），所有操作和状态统计折算为单流。开销统计使用固定噪声seed1101，与测试中的一组输入一致；不是三个噪声种子的平均。

## 参数与Dynamic Buffer

持久动态缓存按单流FP32计数，包含LIF膜电位；不含权重、FFT批处理缓存、反向图、当前帧卷积工作区。共享读出若在线实现，额外需要整段累加11、末20帧环形缓存220、末窗累加11及计数1，共243个标量，三模型相同，未列入下表。

DMP记忆层状态N+d=296个标量。Commit为N+2d+42=378，其中42为门控因果统计（两份前一帧均值和4+36维EMA）。复用W_m m需要额外N=256标量（1024 bytes），因此缓存并非免费。全模型公共LIF状态为49,419标量。

## 计数口径与原论文对应关系

- 核心M=4096,N=256,d=40；fast=nnz(x)N，drive=nnz(x)×(1或d)，候选转移每步d² MAC，候选读取每步Nd MAC。Commit额外门控矩阵每步3904 MAC，并额外进行稳定读取（闭门缓存后按实际开启样本步数×Nd）。两类模型都包括相同的向量状态转移成本；DMP的FFT离线实现在流式映射中转为等价递推。
- 标量B缩放、稳定更新的逐元素乘/加在counts.json单独统计，不能把它们混为稠密MAC。门控特征归约、比较、sigmoid/ReLU和LIF更新未折算为MAC；因此表格不是全部门级运算/全部能耗。卷积/池化非线性控制成本也没有伪装成零。
- 逻辑访问按输入驻留、输出驻留、LIF融合：每个有效矩阵操作读取一个权重；输入向量每步读取一次；状态转移读取旧状态，输出状态写一次；膜电位每步一读一写；门控统计缓存每步读写。缓存方案额外计入闭门时N维读取和开门时N维写入。完整公式见hardware_audit.py的mapping函数。它是显式数据流模型，不是GPU硬件计数器或物理SRAM事务；输入分块、寄存器驻留及存储银行会改变真实访问数。
- 当前eager实现仍在每个时刻进行稠密W_m m，并执行并行affine_scan；counts.json保存其稳定读取MAC以及scan标量操作数。闭门不会自动使torch.Linear省电。脚本执行的缓存参考核验证了可跳过性，但未生成新RTL/ASIC。

## 与原论文能耗评估的关系

原论文arXiv:2512.07602v3（Methods: Implementation and Evaluation Methodology，PDF第18–19页）使用22FDX、QuestaSim/Innovus版图后仿真，并按spike/memory/memory-update/output分项核算。没有公开可直接移植到本视觉网络的每次MAC/SRAM访问能耗常数。本文因此不编造nJ或声称实测功耗降低。

可代入同工艺常数的式子：E_core = N_MAC e_MAC + N_mul e_mul + N_add e_add + R_weight e_weight_read + R_state e_state_read + W_state e_state_write + E_gate-feature/nonlinear/LIF。闭门节省项需减去读取缓存及门控成本。

## 缓存参考实现验证

对全部264样本×19条件，比较缓存重建稳定状态/读取与原并行模型，并重放后续LIF和分类层。最大状态误差3.81e-06；最大读取误差1.53e-05；末层前脉冲不一致计数1；整段及末20帧分类不一致总数0。误差阈值预设：状态atol/rtol=2e-4，读取=3e-4；使用FP32，不声称逐比特相同。

所有参数量、缓存量、逐条件原始计数、参考核校验和能耗系数假设均交付。没有使用SHD新训练或推理来扩充本板块。
